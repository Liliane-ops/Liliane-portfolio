# Liliane-portfolio

A simple personal portfolio website built to practice a professional Git and GitHub workflow.

## About the Project

This project is a personal portfolio website for Liliane Ingabire. It showcases basic information, skills, and professional interests.

## Technologies Used

- HTML
- CSS
- Git
- GitHub

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## Project Purpose

The purpose of this project is to build a simple portfolio website while practicing Git and GitHub collaboration workflows, including branches, commits, pull requests, code reviews, and merges.
